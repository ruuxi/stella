# Modifying Stella Desktop

## Non-obvious gotchas

- There's one `package.json` at the repo root — install all dependencies there.
- Never launch Stella dev servers for testing. Stella is already running for
the user, and starting another dev server can interrupt their active session.
- Never adjust onboarding unless specifically told. The user cannot see it,
so there is no point changing it.
- For broad "modify the Stella UI" work, start at
`desktop/src/routes/__root.tsx`. It owns the shell structure: `ShellTopBar`,
the persistent `ChatColumn`, the route `<Outlet />`, `DisplaySidebar`, and
global dialogs. Then follow into `desktop/src/shell/` for chrome/panels and
`desktop/src/shell/full-shell.layout.css` plus shell-specific CSS files for
layout/styling.
- For background/image theme requests, create or update a real theme in
`desktop/src/shared/theme/themes/`. Do not just set a page/body background.
Stella's UI is mostly glass/transparent, so tune the image overlay, glass
opacity, message bubbles, top bar, panels, and composer together for
readability. Make sure the image is not hidden behind `ShiftingGradient`;
image themes should suppress or bypass the generated gradient as needed.
Assistant messages may need fit-to-content bubbles when the background is
visually busy.
- `desktop/src/routeTree.gen.ts` is auto-generated by Vite's TanStack
plugin on every save. Don't edit it; edit files under
`desktop/src/routes/` instead.
- Top-bar nav entries are discovered from `desktop/src/app/<id>/metadata.ts`
via `import.meta.glob("../../app/*/metadata.ts")` in
`desktop/src/shell/sidebar/app-registry.ts` and rendered by
`desktop/src/shell/sidebar/ShellTopBarNav.tsx`. Add a top-bar app by dropping
a new `metadata.ts`; don't hardcode entries in the nav.
- The voice overlay has no router — features that need to be reachable
from it must flow through `UiState`, not router state.
- `useFullShellChat()` is mounted exactly **once** in
`desktop/src/routes/__root.tsx` inside `<ChatRuntimeProvider>`.
Everything else (chat route, sidebars) reads it via
`useChatRuntime()`. Mounting it elsewhere double-instantiates the
streaming subscription.
## Validation

Run from the Stella install root (the directory containing `desktop/` and
`runtime/`):

```bash
bunx tsgo -p desktop/tsconfig.app.json --noEmit   # renderer (workspace-local TS 7)
bun run electron:typecheck                        # main + preload
bun run lint
bun run test:run -- tests/runtime/sidebar-discovery.test.ts tests/runtime/route-smoke.test.ts
```
